# 结构化摘要示例

当用户要求归纳、摘要或提炼已有材料时，按以下结构输出：

1. 一句话结论。
2. 三到五条关键事实，保留原文中的限定条件和数字。
3. 尚未明确的信息或需要确认的风险。

只使用当前上下文中已有的内容，不补充未经来源支持的事实。原文存在冲突时，应明确列出冲突点，不自行选择其中一个版本作为结论。用户指定格式或长度时，以用户要求为准。
